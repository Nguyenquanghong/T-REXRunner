
Hướng dẫn cách điều khiển:
*Giao diện bắt đầu:
- Nhấn 'Play game' để bắt đầu.
- Nhấn 'High score' để xem điểm cao
- Nhấn 'Exit' để thoát game

*Khi chơi game:
- Nhấn 'UP' để nhảy
- Nhấn 'Down' để cúi
- Nhấn 'Space' để tạm dừng trò chơi & tiếp tục
- Trò chơi kết thúc khi va chạm.

*Giao diện kết thúc:
- Nhấn 'Replay' để chơi lại
- Nhấn 'Back' để trở lại giao diện bắt đầu

*Thông tin khác:
- Ngôn ngữ: C++
- Thư viện: SDL2
- Người phát triển: Nguyễn Quang Hồng

*Cách chạy:
- Chạy file `T-REX-Runner.exe`.
